# DeadlockDoctor

## A Resource & Deadlock Manager

DeadlockDoctor is a user-space Operating Systems and System Programming
project developed in C on Ubuntu Linux.

The project demonstrates how processes can compete for shared resources,
enter waiting states, create circular dependencies, and result in deadlock.

The system provides mechanisms for:

- Process management
- Process lifecycle and state transitions
- User-level scheduling
- Resource management
- Resource allocation and release
- Synchronization and concurrency
- Deadlock detection
- Deadlock diagnosis
- Deadlock recovery
- CLI-based interaction

## Course Alignment

The project primarily demonstrates concepts from:

- CO-2: Processes and Process Control
- CO-6: Concurrency and Synchronization

Supporting concepts may be taken from CO-1, CO-3 and CO-5 where appropriate.
